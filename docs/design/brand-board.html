Layout principles

Artwork first. Clear actions.

  • Keep posters proportional and uncropped on a dark backing.
  • Use a thin border to distinguish neighboring surfaces.
  • Describe viewing progress with text, keeping gold for emphasis.
  • Let long titles wrap and keep actions easy to find.

05

Space to adapt

One visual system, every screen

The app's media grid moves from three columns to two at 991px, then one at 575px. Details stack on small screens, and navigation wraps.

The board uses these breakpoints for its own documentation layout. It is a reference, not a screenshot of the application.

Keep the experience readable

Preserve visible focus, descriptive labels, poster alternatives, and text alongside loading or error indicators. Respect reduced motion.

Accessibility guidance is documented in DESIGN.md. Existing application compliance still requires verification.
